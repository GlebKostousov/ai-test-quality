# Тесты без ИИ-слопа

`ai-test-quality` помогает агенту писать и разбирать тесты. Для нового теста агент называет ошибку, которую тот должен поймать, и выбирает самый дешёвый способ её увидеть. При чистке существующего набора он проверяет, какой сигнал пропадёт вместе с каждым кандидатом на удаление.

Например, у выгрузки есть три условия: вернуть все записи выбранной организации, сохранить повторы и исключить чужие записи. Проверка «все строки принадлежат нашей организации» пропустит пустую выгрузку. В [учебном тесте](examples/test_export.py) сравнивается состав с учётом повторов. Порядок строк по условиям задачи свободный.

## Установка

Склонируйте репозиторий в каталог навыков вашего агента. Для Codex на уровне проекта выполните из корня проекта:

```sh
git clone https://github.com/GlebKostousov/ai-test-quality.git .agents/skills/ai-test-quality
```

Для личной установки используйте каталог пользователя: `~/.agents/skills/ai-test-quality` для Codex или `~/.claude/skills/ai-test-quality` для Claude Code. В новом сеансе попросите агента применить `ai-test-quality`. Для обязательного применения добавьте в инструкции проекта:

> При написании, изменении, ускорении и ревью тестов применяй навык `ai-test-quality`. Учитывай тестовый стандарт проекта.

## Два запроса для начала

- **Написать тест.** «При повторной доставке события заказ иногда создаётся дважды. Найди ближайший тест и проверь, что после повторной доставки сохранён один заказ».
- **Разобрать набор.** «Проверь тесты выгрузки. Покажи, какие ошибки они пропускают. Перед удалением дубля укажи, какой оставшийся тест поймает ту же ошибку».

## Проверить пример

Из корня этого репозитория выполните:

```sh
python -m unittest discover -s examples -v
```

Пример использует стандартную библиотеку Python 3. Если в [функции выгрузки](examples/export_rows.py) временно вернуть пустой список, тест на смешанных данных упадёт. Изменение порядка правильных строк тест допускает.
